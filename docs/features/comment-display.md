# コメント表示

## リアルタイム集約表示

複数の接続から届くコメントをリアルタイムで一つのリストに集約して表示します。どの接続から来たコメントかは接続名で確認できます。

## コメントの種別

コメントは以下の種別に分類されて表示されます。

| 種別 | 説明 |
|------|------|
| 通常チャット | 一般的なコメント |
| 履歴 | 接続前に投稿された過去のコメント |
| 投げ銭 | スーパーチャット等の投げ銭コメント |
| システムメッセージ | 配信サイトからのシステム通知 |

## 投げ銭金額の表示

投げ銭コメントには金額が表示されます。JPY（¥8,000）、USD、EUR など複数の通貨フォーマットに対応しています。

## アバター・バッジ表示

- **アバター**：コメント投稿者のプロフィール画像を表示します。
- **バッジ**：配信者・モデレーターなどの権限バッジを表示します。

## 仮想スクロール

大量のコメントが届いても、仮想スクロール技術により画面に表示されている分だけをレンダリングするため、動作が軽快に保たれます。

## 列のカスタマイズ

コメントリストの列の幅や並び順をドラッグで変更できます。設定はアプリ終了後も保存されます。

## ユーザーによるコメント一括削除の反映

配信者がユーザーのコメントを削除した場合、そのユーザーのコメントがアプリ上でも非表示になります。
