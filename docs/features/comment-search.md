# コメント検索

> **注意**: この機能は `alpha` チャンネルビルドでのみ有効です。

## 概要

受信したコメントをキーワードで検索できます。SQLite による全文検索を使用しており、大量のコメントでも高速に検索結果が表示されます。

## 検索対象フィールド

以下のフィールドを横断的に検索します。

- コメント本文
- ユーザー名
- ユーザー ID
- 接続名

## 使い方

1. 画面上部のタブから「検索」を選択する
2. 検索ワードを入力する
3. 入力に応じてリアルタイムで結果が表示される（300ms のデバウンス）

検索結果は投稿日時の昇順で表示されます。
