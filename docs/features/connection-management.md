# 接続管理

MultiCommentViewer では、複数の配信サイトへの接続を独立して管理できます。

## 接続の追加

「接続を追加」ボタンをクリックすると、新しい接続が作成されます。接続名は自動的に `#1`, `#2`, ... と連番で付与されます。

## URL 入力とサイト自動検出

接続の URL 欄に配信 URL を入力すると、対応する配信サイトが自動的に検出・選択されます。手動でサイトを選び直す必要はありません。

## 接続名の変更

接続名をクリックすることで任意の名前に変更できます。変更した名前は保存されます。

## 接続と切断

- **接続** ボタン：指定した URL への接続を開始し、コメントの受信を始めます。
- **切断** ボタン：接続を停止します。

## 接続の削除

切断状態の接続は削除できます。接続中は削除できません。

## 接続ごとの色設定

各接続に背景色・文字色を個別に設定できます。複数の配信サイトのコメントを色で見分けるのに便利です。

## 複数接続の同時利用

複数の接続を同時に使用できます。各接続は独立して動作するため、一つの接続の操作が他の接続に影響することはありません。

## 接続情報の自動保存

接続の URL・名前・サイト・色設定などはアプリ終了時に自動保存されます。次回起動時に前回の状態が復元されます。
