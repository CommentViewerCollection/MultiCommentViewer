# 開発者向け・デバッグ機能

## ログの表示と検索

設定画面の「ログ」タブからアプリおよびプラグインのログを確認できます。

- **フィルタリング**：ログレベル（error / warn / info / debug / trace）、日時範囲、キーワードで絞り込み可能

## ディレクトリパスの確認

設定画面の「ディレクトリ」セクションから以下のパスを確認できます。

| 項目 | 説明 |
|------|------|
| ログディレクトリ | ログファイルの保存場所 |
| プラグインディレクトリ | EXE プラグインの配置場所 |
| 設定ディレクトリ | 設定ファイルの保存場所 |

## ビルドプロファイル情報

設定画面からビルドモード（Debug / Release）や Rust / Node.js のバージョンなどのビルド情報を確認できます。

## DummyPlugin コマンド

DummyPlugin 接続中は、コメント投稿欄から以下のコマンドを実行できます（動作テスト・開発用途）。

| コマンド | 説明 |
|----------|------|
| `help` | コマンド一覧を表示する |
| `status` | 現在の接続状態を表示する |
| `disconnect` | サーバー側からの切断をシミュレートする |
| `pause` | コメントの自動生成を一時停止する |
| `resume` | コメントの自動生成を再開する |
| `rate <秒>` | コメント生成間隔を設定する（0 = ランダム 1〜5 秒） |
| `comment <ユーザー名> <テキスト>` | 指定内容でコメントを手動生成する |
