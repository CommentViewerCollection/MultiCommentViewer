# プラグイン管理

## 概要

MultiCommentViewer はプラグインシステムにより機能を拡張できます。各配信サイトへの対応はプラグインとして提供されます。

## インストール済みプラグインの確認

設定画面の「プラグイン」タブから、現在インストールされているプラグインの一覧を確認できます。

## プラグインのインストール

プラグインレジストリから配信サイト対応プラグイン等を検索してインストールできます。

1. 設定画面の「プラグイン」タブを開く
2. レジストリからインストールしたいプラグインを選択する
3. 「インストール」をクリックする

## プラグインのアンインストール

不要になったプラグインはアンインストールできます。

## EXE プラグイン

EXE 形式のプラグイン（独立したプロセスとして動作するプラグイン）は、アプリ起動時に自動的に起動されます。プロセスが異常終了した場合は自動的に再起動されます。
