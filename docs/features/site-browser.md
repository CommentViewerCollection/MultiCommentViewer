# サイト・ブラウザ管理

## 対応サイト一覧

設定画面から、アプリが対応している配信サイトの一覧を確認できます。

## ブラウザプロファイルの管理

配信サイトへのログインにブラウザのセッションを使用するため、使用するブラウザのプロファイルを登録します。

- **追加**：ブラウザの種類とプロファイルのパスを指定して登録する
- **削除**：不要になったブラウザプロファイルを削除する

登録したブラウザプロファイルは接続ごとに選択して使用します。

## ブラウザ Cookie による認証

登録したブラウザプロファイルの Cookie を使って、配信サイトへのログイン認証を行います。ブラウザで既にログイン済みのアカウントをそのまま利用できます。

## アカウント情報の表示

接続後、その接続に使用しているアカウント情報（ユーザー名・アイコン等）を確認できます。意図したアカウントで接続されているかを確認するのに便利です。
