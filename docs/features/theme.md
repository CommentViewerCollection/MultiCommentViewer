# 外観・テーマ

## プリセットテーマ

以下の 3 つのプリセットテーマが用意されています。

| テーマ名 | 説明 |
|----------|------|
| dark | 暗い背景のダークテーマ |
| modern-dark | モダンなデザインのダークテーマ |
| light | 明るい背景のライトテーマ |

設定画面からワンクリックで切り替えられます。

## カスタムテーマ

以下の色要素をそれぞれ個別に設定してオリジナルのテーマを作成できます。

| 要素 | 説明 |
|------|------|
| メイン背景色 | コメントリストの背景色 |
| サイドバー背景色 | サイドバー・ヘッダーの背景色 |
| 入力欄背景色 | テキストボックスの背景色 |
| ボタン背景色 | ボタンの背景色 |
| テキスト色 | 文字の色 |
| ボーダー色 | 境界線の色 |
| タイトルバー背景色 | タイトルバーの背景色 |
| タイトルバーテキスト色 | タイトルバーの文字色 |
