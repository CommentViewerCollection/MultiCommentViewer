# ユーザー管理

## ユーザー一覧

コメントを投稿したユーザーの一覧を確認できます。最後にコメントした日時の降順で表示されます。

## ニックネーム設定

ユーザーに対して独自のニックネームを設定できます。設定したニックネームはコメントリストのユーザー名欄に表示されます。

## MCV NG 設定

特定のユーザーのコメントをアプリ側で非表示にできます。配信サイト側の状態には影響しません。

- ユーザー一覧の「MCV NG」チェックボックスをオンにすると、そのユーザーのコメントがコメントリストに表示されなくなります。

## サイト側ブロックの反映

Twitch など一部の配信サイトでは、サイト側でブロックしたユーザーの情報が自動的に MCV の NG リストに反映されます。
